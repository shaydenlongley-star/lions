# Shaydefy Outreach — Messages & Process Guide

---

## PROCESS RULES (follow every round)

### Who to target
- Only businesses with **no website** OR **website score ≤4**
- Score 5+ = skip, even if the site looks bad
- No exceptions — if in doubt, run scorer.js first

### Before building any mockup
1. **Always look up their Instagram/Facebook logo first** — the brand color is in the logo, not guessed
2. Screenshot their profile or share it here so the hex is confirmed, not inferred
3. If Instagram requires login, check their Facebook page or Google Maps listing for logo
4. Don't build the mockup until you have the actual brand color — wrong colors kill the credibility of the mockup

### Building the mockup
- Screenshot at **1440px width** in Chrome DevTools (toggle device toolbar → set custom width 1440)
- Capture the full hero section — nav down to the tags
- Save screenshot before sending

### Writing the messages
- **No emojis** — clean, direct, confident tone
- **Custom message per channel** — email and Instagram DM are different formats
  - Email: longer, more specific pain points, attach mockup as image
  - Instagram DM: short, one specific hook, reference the mockup casually
- Always reference **one specific thing** about their actual business — not generic
- Sign off as **Shayden** with **shaydefy.com** — no agency language
- Attach the mockup screenshot to email Touch 1 and to IG DM variant C

### Sending order
- Email + Instagram DM simultaneously for businesses that have both
- WhatsApp only as warm follow-up after no email reply
- Max 20 emails/day across all targets

### Tracking
- Log each contact in this file under their round with status
- Mark: **Sent / Replied / Interested / Closed / Dead / Skipped**
