# Outreach Research Checklist

Run this for every business before writing a single line in launcher.html.

---

## For each target, find:

### Identity
- [ ] Confirmed business name (exact spelling)
- [ ] Location (area/soi/district)
- [ ] Business type / niche

### Channels (search ALL of these — don't stop after finding one)
- [ ] **Instagram handle** — search `[name] Bangkok Instagram`, confirm follower count
- [ ] **Email** — check Instagram bio, Facebook About, Google Maps listing, website contact page
- [ ] **WhatsApp** — check Instagram bio, Facebook, Google Maps phone number (strip leading 0, prepend 66)
- [ ] **LINE ID** — check Instagram bio, Facebook, any Thai-facing listings
- [ ] **Phone number** — Google Maps, website (convert to WhatsApp format: drop leading 0, add 66)
- [ ] **Website** — if they have one, note the URL and check if it's bad/good

### Pain points (must be specific, not generic)
- [ ] Do they have a website? If yes — does it rank? Does it reflect their quality?
- [ ] Are aggregators (GoWabi, ClassPass, TripAdvisor) appearing above them in search?
- [ ] What's missing: pricing, booking form, schedule, artist/staff profiles, menu?
- [ ] Is their portfolio/content trapped only on Instagram?

---

## Search queries to run (in parallel)

```
[name] Bangkok Instagram
```

---

## Before writing launcher contacts

- [ ] Every handle/email/phone verified against search results — no guessing
- [ ] Pain points reference something real and specific to that business
- [ ] If they have a website, pain points are "bad site" not "no website"
- [ ] Follower counts accurate (used in T1 messages)
